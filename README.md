# 🌕 Loy Krathong Festival 3D (งานเทศกาลลอยกระทง 3 มิติ)

เว็บแอปพลิเคชันจำลองบรรยากาศงานวัดและเทศกาลลอยกระทงแบบ 3 มิติ พัฒนาด้วย **Three.js** และ **Vite**

## ✨ ฟีเจอร์หลัก (Features)
- 🛕 **วัดไทยและพระเจดีย์สีทองสว่างไสว:** พร้อมโบสถ์ ซุ้มประตู เสาไฟวัด และกำแพงวัด
- 🏮 **โคมลอยและพลุดอกไม้ไฟ:** โคมลอยลอยขึ้นสู่ฟากฟ้าอย่างต่อเนื่อง พร้อมการจุดพลุเฉลิมฉลอง
- 🌊 **แม่น้ำและกระทงลอยน้ำ:** ฟิสิกส์คลื่นน้ำกระทบกระทั่ง พร้อมระบบอธิษฐานและปล่อยกระทงของผู้เล่น
- 👥 **ฝูงชนเดินเที่ยวงานวัด:** คนเดินเที่ยวชมงานรอบพระเจดีย์ ท่าน้ำ และซุ้มร้านค้า
- 🎶 **ดนตรีไทยประกอบเทศกาล:** เพลงลอยกระทงบรรเลงด้วยเสียงระนาด ขลุ่ย ฉิ่ง-ฉับ และกลองรำวง
- 🎯 **มินิเกมงานวัด:** เกมปาโป่ง (Dart Balloon) และเกมตักไข่นกกระทา

## 🚀 การติดตั้งและรันโปรเจ็กต์ (Getting Started)

```bash
# ติดตั้ง dependencies
npm install

# รันโหมด Development
npm run dev

# บิลด์สำหรับ Production
npm run build
```

## 🛠️ เทคโนโลยีที่ใช้
- [Three.js](https://threejs.org/)
- [Vite](https://vitejs.dev/)
- Web Audio API (Synthesizer สำหรับเครื่องดนตรีไทย)
