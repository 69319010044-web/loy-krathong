# Loy Krathong Festival 3D (ประเพณีลอยกระทง 3 มิติ) 🪷✨

เว็บแอปพลิเคชัน 3D Interactive "เทศกาลลอยกระทง" จำลองบรรยากาศงานวัดริมแม่น้ำเจ้าพระยา ด้วย React, Three.js และ Tailwind CSS

## 🌟 ฟีเจอร์เด่น
- **วัดไทยและพระมหาเจดีย์สีทอง (Thai Temple & Stupa):** อุโบสถหลังคาซ้อน 3 ชั้น เสาระเบียง บันไดนาคราช และพระเจดีย์ทองอร่าม
- **โซนงานวัดสุดคึกคัก (Vibrant Temple Fair):** ชิงช้าสวรรค์หมุนได้จริง, ซุ้มร้านค้า 6 ร้านพร้อมป้ายไฟนีออน, ธงราวหลากสี และฝูงหิ่งห้อย
- **กระทงและโคมลอยสมจริง (Krathongs & Sky Lanterns):** กระทงใบตองธรรมชาติลอยล่องตามกระแสน้ำ และโคมลอยลอยขึ้นสู่ท้องฟ้า
- **ผู้คนขยับได้ (Live Animated Crowd):** มีแอนิเมชันคนเดินเที่ยวชมงานวัด, ก้มปล่อยกระทงที่โป๊ะท่าน้ำ, ยืนพนมมือไหว้ และมองดูพลุ
- **ระบบเสียงบรรยากาศ (Web Audio API Synthesizer):** เสียงเพลงรำวงวันลอยกระทง (ระนาดเอก • ขลุ่ย • ฉิ่ง), เสียงระฆังวัด, ประทัด และเสียงสายน้ำ
- **ปรับช่วงเวลาท้องฟ้าได้ 3 แบบ:** ยามเย็นพลบค่ำ (Sunset), หัวค่ำงานวัด (Twilight), คืนวันเพ็ญเดือนสิบสอง (Full Moon)
- **โหมดถ่ายภาพ (Photo Mode):** ซ่อน UI เพื่อชมทัศนียภาพแบบเต็มจอ

## 🚀 วิธีการติดตั้งและรันโปรเจกต์
```bash
# ติดตั้ง dependencies
npm install

# รัน Development Server
npm run dev

# Build สำหรับ Production
npm run build
```
